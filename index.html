使用说明
1. 选择“体素网格”或“事件流”绘图模式。
2. 设置 X / Y / Z 空间尺寸，并选择自由 3D 或论文视图。
3. 体素模式可逐格编辑；事件流模式可生成交替活动带、时空簇或均匀事件。
4. 分别设置外侧线和内部/遮挡线的样式。
5. 调整到满意视角后导出 SVG、PNG 或可编辑 PPT。
6. 用工程 JSON 保存两种模式的当前配置，之后可继续编辑。
